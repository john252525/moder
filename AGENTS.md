# Agent instructions

> **Точка входа.** Прочитай это первым делом при старте сессии, до любых правок кода.

## Порядок чтения при старте

1. `docs/memory/PROJECT.md` — что за продукт и как устроен (медленная память)
2. `docs/memory/STATE.md` — где мы сейчас (быстрая память, **самое важное**)
3. `docs/memory/CONVENTIONS.md` — как здесь принято писать код
4. последние 2–3 файла из `docs/memory/iterations/` (по имени = по дате)

По необходимости: `DECISIONS.md` (почему так, а не иначе), `GLOSSARY.md` (термины), `BACKLOG.md` (что сознательно отложено).

## Правила

- **Не переизобретай.** Прежде чем предлагать архитектурное изменение — проверь `DECISIONS.md`.
- **Не «чини» отложенное.** Если это в `BACKLOG.md` как known issue — согласуй, прежде чем трогать.
- **Один источник правды.** «Где мы сейчас» живёт только в `STATE.md`, не дублируй его в `PROJECT.md`.
- **Ссылайся на код.** В iteration-файлах указывай конкретные файлы и функции.

## End of iteration checklist

1. Все тесты проходят (или явно описано, почему нет)
2. Обнови `docs/memory/STATE.md` — секции Done / In progress / Next / Blockers
3. Создай `docs/memory/iterations/YYYY-MM-DD-NNN-<slug>.md` по шаблону (см. `docs/memory/iterations/_TEMPLATE.md`)
4. Если было архитектурное решение — допиши ADR в `DECISIONS.md`
5. Если появился TODO/техдолг — допиши в `BACKLOG.md`
6. `git add -A && git commit -m "iter NNN: <summary>" && git push`

## Что это

**moder** — сервис премодерации контента для автономных (stateless) агентов. Агенты генерируют исходящие действия (письма, статьи, правки сайта, рекламу), человек-модератор просматривает их в единой очереди и одобряет либо отклоняет с причиной. Одобренное забирает devops-воркер и применяет (отправка/публикация/деплой).

Идея: **outbox/inbox паттерн с human-in-the-loop** — один источник правды, один UI, один процесс ревью, обратная связь агенту через причину отказа.

## Для кого

- **Агенты** (машинные клиенты) — кладут записи в очередь через REST API.
- **Модератор** (человек) — смотрит очередь в веб-UI, одобряет/отклоняет.
- **Devops-воркер** — поллит одобренное и применяет.
