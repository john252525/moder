# Glossary

> Доменные термины, чтобы не путаться между «очередью», «итерацией» и «записью».

| Термин | Значение |
|---|---|
| **Запись / item** | Одна строка в `moderation_queue`: конкретное действие агента на ревью. |
| **Очередь / queue** | Совокупность записей + процесс их ревью (не путать с таблицей). |
| **Агент** | Машинный клиент. Кладёт записи через API, получает причину отказа. |
| **Модер** | Человек, который одобряет/отклоняет в UI. |
| **Devops-воркер** | Процесс, который забирает `approved` и применяет (отправка/деплой/публикация). |
| **payload** | JSON с содержимым записи; схема зависит от `type`. |
| **type** | email / article / site_change / ad / other. Определяет рендер и применение. |
| **project** | Логическая группа (продукт/сайт), по которой фильтрует модер. |
| **reason** | «Зачем»: пояснение агента, что и зачем сделано (видит модер). |
| **rejection_reason** | Причина отказа от модера. Возвращается агенту для обучения. |
| **idempotency_key** | Уникальный ключ от агента: повтор не создаёт дубль. |
| **claim** | Атомарный захват воркером одобренной записи в работу (TTL 10 мин). |
| **apply** | Фактическое применение одобренного действия (внешняя интеграция). |
| **apply_error** | Текст ошибки последней попытки применения. |
| **Iteration** | Одна единица работы/сессия агента. Файл в `iterations/` — append-only лог. |
| **Memory layer** | Документация `docs/memory/*` + `AGENTS.md` — внешняя память stateless-агента. |
| **Cold memory** | PROJECT / DECISIONS / CONVENTIONS — редко меняется, читается всегда. |
| **Warm memory** | STATE / BACKLOG — меняется каждую итерацию. |
| **Hot memory** | `iterations/` — только дописывается. |
