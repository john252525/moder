# Iteration 011 — мобильный SPA (/m/)

Date: 2026-11-19
Commit: 05286d2

## Goal
С телефона старый серверный UI неудобен. Сделать адаптивный UI, изолированно,
чтобы при неудаче снести одной командой.

## Changes
- `www/public/m/`: статический SPA (index.html, app.css, app.js, README.md), без сборки.
- Слева постоянный узкий сайдбар задач (тап-зона >=56px), свой скролл.
- Справа деталь со своим скроллом, кнопки действий закреплены внизу.
- URL `/m/<uuid>`, History API (back/forward), без перезагрузок.
- Фильтры — bottom-sheet (☰). Рендеры payload повторяют серверные: письмо (iframe),
  статья (markdown), diff сайта, реклама.
- Авторизация: `X-Moder-Token` из sessionStorage либо `?token=` (чистится из URL).
- `nginx/default.conf`: `location /m/` со SPA-fallback. Старый UI и API не тронуты.

## Tests
- статика и /m/<uuid> отдаются (200), старый `/` 401->login->200, API 200.
- рендер: все 4 типа payload различаются, кнопки ✓/✗ видны у pending.
- прямые ссылки: запись открывается и появляется в сайдбаре.
- размеры: 390x844, 768x1024, 1440x900 — рендерится корректно.
- секреты: реальные значения из .env в /m/ не встречаются.

## Notes / next
- Снос: `rm -rf www/public/m` + убрать блок `location /m/` в nginx.
- Возможные улучшения: свайп-навигация, bulk-выбор в сайдбаре, pull-to-refresh.
