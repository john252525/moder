## Goal
Построить memory layer для stateless-агента (AGENTS.md + docs/memory/*) и подготовить
проект к публичному коммиту на GitHub: убрать секреты из кода, добавить .gitignore/.env.example.

## Changes
- `AGENTS.md`: точка входа — порядок чтения, правила, end-of-iteration checklist.
- `docs/memory/PROJECT.md`: продукт, стек, архитектура, схема БД, структура репо.
- `docs/memory/STATE.md`: Done / In progress / Next / Blockers.
- `docs/memory/DECISIONS.md`: ADR-001..005 (одна таблица+JSON, идемпотентность, approved≠applied, vanilla PHP, fail-closed auth).
- `docs/memory/CONVENTIONS.md`: стиль PHP/структура/безопасность/ошибки/git.
- `docs/memory/GLOSSARY.md`, `docs/memory/BACKLOG.md`, `docs/memory/iterations/_TEMPLATE.md`.
- `.gitignore`: .env, logs/, mysql/, скриншоты, кэши, редакторы.
- `.env.example`: шаблон всех переменных с плейсхолдерами.
- `www/app/config.php`: переписан в чистый `return [...]` (убрана функция — фикс
  «Cannot redeclare function toklist()»), токены через локальный замыкание-хелпер.
- `www/app/core.php`, `www/app/db.php`: убран двойной require config.php, используют `cfg()`.
- `www/app/ui.php`: fail-closed — без `MODER_TOKEN_MODER` отдаёт 503, секрет cookie
  выводится из токена если `MODER_UI_SECRET` пуст.
- `docker-compose.yml`: убраны dev-дефолты токенов, значения только из `.env`.
- `www/bin/devops-worker.sh`, `www/bin/demo-agents.sh`: требуют токен из ENV, иначе exit 2.

- `curl /health` -> 200, php 8.5.12, mysql 9.4.0.
- API: валидный токен -> 200, пустой/неверный -> 401.
- UI: без cookie -> 401 (логин), логин по токену -> 302 -> список 200.

- `grep` по `.env.example` — реальных секретов нет (только change-me плейсхолдеры).
- php -l по всем изменённым файлам — без ошибок; bash -n по скриптам — ок.
