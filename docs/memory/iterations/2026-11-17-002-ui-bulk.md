# Iteration 002 — UI bulk-действия, быстрые решения, отзыв, hover-превью

Date: 2026-11-17
Commit: 2f8a491

## Goal
Сделать ревью очереди быстрым: массовые действия, решения в один клик, отзыв
одобрения, превью письма при наведении. Плюс документация API для агентов.

## Changes
- `www/app/ui.php`: чекбоксы + select-all; sticky bulk-панель (approve/reject с причиной);
  быстрые ✓/✗ в строке (отказ через prompt); кнопка ↺ отзыва в строке и в карточке;
  hover-модалка письма (from/to/subject/body); CSS+JS в layout.
- `www/app/ui.php`: новый роут `POST /bulk`, `POST /item/{id}/revoke`; `ui_bulk()`;
  `ui_action()` понимает revoke (approved -> pending, сброс reviewed_*).
- `www/app/config.php`: `ui.email_hover` из ENV; фикс парсинга строки "0" (falsy).
- `docker-compose.yml`, `.env.example`: `MODER_UI_EMAIL_HOVER`.
- `www/app/API.md`: полный пример POST письма + минимально обязательные поля
  + как мониторить отказы (по id, по статусу rejected/archive).

## Tests
- bulk approve 2 записей -> approved, reviewed_by=moder-ui.
- revoke -> pending, событие `revoked`.
- bulk reject без причины -> блокируется; с причиной -> rejected + rejection_reason.
- MODER_UI_EMAIL_HOVER=0 -> data-hover=0; =1 -> 2. (потребовался --force-recreate).
- Снаружи через Caddy: /, /health, /login, /phpmyadmin/ — ок.
- php -l и bash -n — чисто; логи без fatal.
