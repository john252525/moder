## Goal
Агенты жаловались: 'GET возвращает пустоту'. Причина — запрос на http:// получал
308 с Content-Length: 0. Плюс сделать фолбэки API информативными.

## Changes
- Caddy `/etc/caddy/sites/moder.apitly.ru.caddy`: порт 80 для `/api/*` отдаёт
  JSON-тело с подсказкой (через `route{}`, иначе авто-редирект Caddy перекрывает).
- `www/app/api.php`: OPTIONS возвращает допустимые методы; терпим хвостовой слэш;
  `/api` -> `/api/queue`; неизвестный эндпоинт -> 404 со списком всех известных.
- `www/app/API.md`: раздел HTTP vs HTTPS + таблица кодов ошибок.
